## How It Works

1. User clicks "Sign in with Google" button
2. App redirects to \/api/auth/google\
3. Passport redirects to Google OAuth consent screen
4. User authorizes the app
5. Google redirects back to \/api/auth/google/callback\
6. Passport exchanges code for user profile
7. App checks if user exists by email:
   - **New user**: Creates account automatically
   - **Existing user**: Logs them in
8. Redirects to dashboard or onboarding

## Security Features

- ✅ OAuth users get random secure passwords (won't use them)
- ✅ Email is the primary identifier for matching users
- ✅ JWT token generated for mobile clients
- ✅ Session management via Redis
- ✅ Google profile data not stored (only email and name)
